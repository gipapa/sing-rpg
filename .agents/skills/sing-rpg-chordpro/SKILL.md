# Sing RPG ChordPro

製作能在本專案正確顯示、依 BPM 捲動、點句跳轉的 UTF-8 歌譜。以本專案的讀譜器為準，不假設所有 ChordPro 指令都受支援。

## 先確認素材與用途

- 保留使用者提供的歌詞、和弦位置、歌曲版本、調性、Capo 與段落順序。資料缺漏時指出缺項，不把猜測的歌詞、和弦、BPM 或拍數寫成原曲事實。
- 「我的歌本」匯入檔只需產生 `.cho`，由使用者在營地匯入、編輯與匯出。除非要求內建／公開發布，不將個人譜加入示範清單。
- 要隨網站發布的譜才放進 `songs/`，並確認內容可公開發布；在 `songs/index.json` 加入不重複的 `id` 與相對 `file`。個人資料不需要進 repo。
- 使用者指定歌曲時，交付該歌曲的可得內容；素材不足就標明缺項，不用另一首示範曲取代。

## 專案格式

輸出明文 UTF-8 `.cho`，將和弦插在對應歌詞前，不用空白字元對齊上下兩排：

```chordpro
{title: 旅途示例}
{artist: 原創示例}
{key: C}
{capo: 0}
{tempo: 90}
{time: 4/4}

{start_of_verse: 主歌}
|[C]風吹向山谷 [G]輕聲唱 |[Am]星光陪我 [F]到遠方 |
{end_of_verse}

{start_of_chorus: 副歌}
{beats: 6}
[F]這句有六個四分音符拍 [G]再出發
{end_of_chorus}
```

示例文字只示範格式。實際內容沿用使用者提供或可使用的素材；只填入已知的曲名、作者、調性、Capo 等資料。

專案慣例與限制：

- `{tempo: 90}` 的單位是每分鐘四分音符拍數。若來源的 BPM 以附點四分音符計，乘以 `1.5` 換成四分音符 BPM，再註明換算。
- `{time: 4/4}` 指定拍號。每小節四分音符拍數是 `分子 × 4 / 分母`；例如 3/4 是 3 拍、6/8 是 3 拍。時長秒數是 `四分音符拍數 × 60 / BPM`。
- 用 `|` 劃分完整小節；同一小節中更換多個和弦不會增加小節拍數。保留 `G/B`、`Am7/G`、`Cadd9` 等完整和弦名稱。
- `{beats: 6}` 是本站擴充，只指定**下一行**的四分音符拍數，適合弱起、跨句或不完整小節；後面的行不會沿用。沒有歌詞的間奏也要寫出和弦／休止的小節，不能只寫「間奏八小節」註解來代替時間。
- `{tempo: ...}`、`{time: ...}` 及 `{meta: tempo ...}`、`{meta: time ...}` 可在曲中變更，從下一個樂譜行起生效。
- 每個可點擊的演唱句盡量各佔一個來源行；手機自動換行不會增加拍數。點擊該行會跳到其起點，播放中持續播放，暫停中維持暫停。
- 依實際演唱順序寫出重複段落。讀譜器不展開 `:|`、`×2`、D.C. 或跳房子；註解與段落標題不佔播放時間。
- `[C]` 只有和弦位置，沒有時值。未標小節／拍數的行會按每個和弦一小節估算，純歌詞行按一小節；缺拍號以 4/4 估算。精確捲譜應補上有依據的小節或 `{beats: ...}`，不能為消除估算而捏造時長。
- 文字 TAB 用 `{start_of_tab}`／`{end_of_tab}` 或 `{sot}`／`{eot}`。連續弦線作為一組計時，小節只算一次；不同組之間留空行。
- 讀譜器支援基本 metadata、主副歌等段落、註解與文字 TAB；沒有實作完整 ChordPro 排版、音符時值或反覆導航。不要依賴未實作的指令控制播放。

## 驗證與交付

從專案根目錄使用實際 parser 與時間軸檢查：

```sh
node .agents/skills/sing-rpg-chordpro/scripts/check-score.mjs --strict songs/journey.cho
```

可一次傳入多份檔案。工具會檢查 UTF-8、大小限制、BPM、可計時內容、總拍數、時長與估算狀態。`--strict` 會將估算判為未通過；不含 `--strict` 時允許估算但會列出警示。素材不足的草稿可保留估算並回報原因，不捏造拍數來通過檢查。

核對輸出的總小節／拍數與已知曲式、前奏、間奏及結尾，尤其留意弱起、反覆與速度變更。需要確認排版時，在本機網頁匯入檔案，查看手機直橫向的和弦位置、逐句跳轉與捲動。

交付 `.cho` 路徑、已知的 BPM／拍號與總時長，以及尚待確認的項目。只有修改 parser、時間軸或匯入邏輯時才額外跑相關程式測試；純歌譜編寫先使用上述內容檢查。
