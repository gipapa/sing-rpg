# 伏雷戰鼓 · 九霄雷奏

鼓手八次引雷，八面雲鼓逐一甦醒。第九面主鼓在敵人頭頂接住回聲，把最後一拍送入大地。

| 起點（秒） | 畫面 |
| --- | --- |
| 0 | 特寫掌邊小鼓的銅釘與鼓皮，鼓槌懸起。 |
| 1.15 | 鼓手試槌，遠處的雲壓低。 |
| 2.35 | 前四拍向高處傳遞，每拍亮起一面鼓。 |
| 4.15 | 全景接後四拍，雲鼓之間連起分岔電弧。 |
| 5.95 | 鏡頭推向八道回聲的終點，第九面主鼓從雷雲落下。 |
| 7.25 | 切回主角，最後一次舉槌。 |
| 8.35 | 主鼓震動，折線雷脈逐段往下生長。 |
| 9.05 | 雷尖懸在目標頭頂，鼓槌與鼓面之間留一線空隙。 |
| 9.40 | 第九拍落下，雷脈接地，電流向兩側爬開。 |
| 10.40 | 電光熄滅，八面鼓的殘響依序退去。 |
| 11.60–13.10 | 雲下出現招式字卡。 |
