# 白潮三叉戟 · 滄海王令

世界座標為 480×240，主角腳底 (150,178)、握點 (159,163)、敵人腳底 (330,178)。
全長 15350 ms，命中 11650 ms（76%），停格 11250–11650 ms，命中後 280 ms 為 10% 速度。
所有命中視覺代表同一次傷害，計算仍由原有戰鬥流程處理。
