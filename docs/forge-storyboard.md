# 赤爐重鎚 · 熔心天墜

主角以手中兵器敲亮一枚爐印。地火沿戰場流向敵人，將三塊鐵胚鑄成一柄懸鎚。主角落手，兩側鎖鏈鬆脫，巨鎚在敵人腳下壓出一圈熔岩。
