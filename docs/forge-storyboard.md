# 赤爐重鎚 · 熔心天墜

主角叩地喚醒山腹裡的熔爐。鐵沿著手中武器長成一柄巨鎚，主角沉肩扛起，掄過頭頂。鎚面觸地時，爐口兩側的玄武岩錯開，熔流穿過裂口，直到收招仍清楚可見。

| 時間（秒） | 分鏡 | 畫面與動作 |
| --- | --- | --- |
| 0–1.45 | 起火 · 一鎚叩地 | 近看主角抽回武器、敲地，第一簇火星從鎚下彈起。 |
| 1.45–3.45 | 回聲 · 山腹開爐 | 從落鎚處拉遠，讓敵人與身後亮起的爐口一同入鏡。 |
| 3.45–5.35 | 引鐵 · 火沿柄走 | 從握柄跟向延伸的鎚柄。鐵胚從兩側靠向鎚心。 |
| 5.35–7.00 | 合鍛 · 鎚頰咬合 | 楔形鎚尾與厚重的敲擊面合攏，鎚心留下一道窄橙光。 |
| 7.00–8.34 | 扛山 · 沉鐵過肩 | 主角壓低重心，向後移身把鎚扛過肩，鏡頭跟著抬高。 |
| 8.34–9.44 | 蓄勢 · 山門一線 | 主角再向後沉半步。鏡頭拉開，讓握柄、鎚面和敵人同框。 |
| 9.44–10.08 | 掄擊 · 一弧越頂 | 主角向前送肩，鎚頭加速越頂，熱痕沿敲擊面的弧線掠過。 |
| 10.08–10.45 | 懸息 · 鎚下留隙 | 鎚面在敵人上方停一拍，鏡頭停震，火屑幾乎靜止。 |
| 10.45–11.45 | 落砧 · 山脊錯斷 | 鎚面下壓，敵人退飛，碎石向兩側爆開，後方山壁錯位。 |
| 11.45–12.65 | 餘火 · 斷層見金 | 鏡頭拉遠，熔流湧進裂口。主角從落擊姿勢緩緩收鎚。 |
| 12.65–14.00 | 終幕 · 熔心天墜 | 巨鎚退回原本的尺寸，字卡出現在開裂的山腹前。 |

全招以 Canvas 繪製。減少動態效果時使用固定全景，舉鎚時略縮鎚柄，保留命中時的觸及距離，同時減少火屑、碎石與敵人的擊退幅度。
