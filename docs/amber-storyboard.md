# 琥珀王刃 · 砂皇獅吼

刀上的琥珀在沙丘上空裂開，鬃毛由碎片拼成的獅王探出頭來，沿刀鋒所指吐出一道壓低沙海的吼浪。

| 2.85 | 拉遠看琥珀在空中長大，沙丘朝它聚攏。 |
| 4.20 | 外殼分離，獅首和層疊的金鬃在逆光中現形。 |
