# ChordPro 歌本

歌本無需加密或解鎖。`index.json` 列出隨網站發布的示範譜，每首歌以明文 `.cho` 儲存；使用者匯入、建立與編輯的歌譜存於目前瀏覽器的 IndexedDB，不上傳到 GitHub 或其他伺服器。

## 營地管理

在營地按「歌本」：

- **新增**：以 ChordPro 格式建立歌譜。
- **匯入譜檔**：支援多個 `.cho`、`.chordpro`、`.chopro`、`.crd`、`.chord`、`.pro`、`.txt`，以及本站匯出的歌本 JSON。文字檔以 UTF-8 讀取。
- **編輯／編輯副本**：編輯「我的歌本」會更新原譜；編輯示範譜會另存到「我的歌本」。
- **刪除**：移除個人的歌譜，需確認後才刪除；內建示範保留。
- **匯出這首 .cho**：下載所選歌曲的原始 ChordPro 文字。
- **匯出我的歌本**：將全部個人歌譜與閱讀設定匯出成明文 JSON，可在另一台裝置匯入。內建示範不包含在這份備份中，需要時可單首匯出。舊備份中的像素捲動速度會被略過，改依 BPM 播放。

整次匯入會先檢查所有檔案，再以同一筆 IndexedDB transaction 儲存，失敗時不會只留下部分歌曲。匯入會產生新的本機 ID，不依備份中的 ID 覆寫其他歌曲。相同譜面內容會略過；匯入 JSON 備份時也會還原已存在歌曲的閱讀設定。未儲存的編輯在關閉前會要求確認捨棄。

單首譜最多 256 KB，個人歌本最多 500 首、合計 10 MB。每次選取的匯入檔案合計最多 10 MB。

## 戰鬥閱讀

戰鬥時按「♬ 歌本」，只顯示選曲、歌詞與和弦，以及譜面下方的播放（三角形）與暫停按鈕。新增、編輯、刪除、匯入、匯出與移調設定僅在營地提供。每首歌的字體與移調會保存在 IndexedDB，進入戰鬥時沿用。

捲譜依 BPM、拍號與譜面拍數建立時間軸，再按照每行在畫面上的高度平滑捲動。字體、螢幕尺寸與自動換行不會改變音樂時長。播放後標示目前行，暫停會保留拍點；關閉再開啟同一首未修改的歌譜仍可繼續。切到背景、手動觸控／滾輪操作也會暫停，手動捲到另一段再播放會從該處繼續。

自行播放外部音樂並在起點按播放；程式不會讀取或追蹤其他音樂 App 的播放時間。

### 拍數標記

`{tempo: 90}` 表示每分鐘 90 個四分音符拍，`{time: 4/4}` 表示每小節四拍。小節用 `|` 分隔，例如：

```chordpro
{tempo: 90}
{time: 4/4}
|[C]第一個小節 [G]中途換和弦 |[Am]第二個小節 |
```

這行共有兩小節、八拍，所需時間為 `8 × 60 / 90` 秒。和弦數量不會改變已標示的小節拍數。6/8 的一小節換算成三個四分音符拍；若 BPM 是以附點四分音符表示，請先換算成四分音符 BPM。

需要弱起、不完整小節或特殊時長時，可使用本站擴充指令 `{beats: 6}`，指定下一行共有六個四分音符拍。這個數值只作用於下一行，不影響後面的行。曲中 BPM 與拍號變更會從指定處起生效。文字 TAB 的連續六線視為同一組計算，不會把每根弦重複計拍。

只有 `[C]` 之類的和弦標記無法確定時值。未標小節或明確拍數的行，暫按每個和弦一小節（純歌詞行按一小節）估算；未標拍號時以 4/4 估算，並顯示「拍數估算」。可在營地補上小節線或 `{beats: ...}` 來精確計時。反覆記號不會自動展開，請將重複段落寫出；含反覆記號的譜也會標示估算。缺少 BPM 時暫停自動捲譜，仍可手動閱讀。

## 資料保存

資料庫名稱為 `sing-rpg-songbook`（版本 1），使用 `songs` 與 `settings` 兩個 object stores。只有最後選取的歌曲 ID 放在 `localStorage`。歌譜與閱讀設定都不會發送到網路。

保存範圍是目前裝置、瀏覽器與網站來源，不會跨裝置同步。清除網站資料、無痕工作階段結束或瀏覽器清理儲存空間可能移除資料，請使用匯出功能保留備份。無法使用 IndexedDB 時仍可閱讀與匯出內建示範，新增／匯入／編輯會停用，不會宣稱已保存。

## 專案內新增示範

在 `songs/` 放入可隨網站公開發布的 UTF-8 ChordPro 譜，再編輯 `index.json`：

```json
[
  { "id": "my-example", "file": "my-example.cho" }
]
```

`id` 使用不重複的英文字母、數字、底線或連字號。`file` 相對於 `songs/`，只能指向本站該目錄下的檔案。個人匯入的譜不需放進專案。

基本資訊可以記成：

```chordpro
{title: 歌名}
{artist: 作者}
{key: C}
{capo: 0}
{tempo: 90}
{time: 4/4}
```

讀譜器支援行內 `[C]` 和弦、段落、註解、文字 TAB、BPM 與拍號；`{meta: tempo 90}` 與 `{meta: time 4/4}` 也可使用。再次指定速度或拍號會在該處標示變更。所有譜面以純文字呈現，不執行 HTML；未支援的獨立指令會略過。
