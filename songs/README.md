# ChordPro 歌本

歌本無需加密或解鎖。`index.json` 列出隨網站發布的示範譜，每首歌以明文 `.cho` 儲存；使用者匯入、建立與編輯的歌譜存於目前瀏覽器的 IndexedDB，不上傳到 GitHub 或其他伺服器。

## 營地管理

在營地按「歌本」：

- **新增**：以 ChordPro 格式建立歌譜。
- **匯入譜檔**：支援多個 `.cho`、`.chordpro`、`.chopro`、`.crd`、`.chord`、`.pro`、`.txt`，以及本站匯出的歌本 JSON。文字檔以 UTF-8 讀取。
- **編輯／編輯副本**：編輯「我的歌本」會更新原譜；編輯示範譜會另存到「我的歌本」。
- **刪除**：移除個人的歌譜，需確認後才刪除；內建示範保留。
- **匯出這首 .cho**：下載所選歌曲的原始 ChordPro 文字。
- **匯出我的歌本**：將全部個人歌譜與閱讀設定匯出成明文 JSON，可在另一台裝置匯入。內建示範不包含在這份備份中，需要時可單首匯出。

整次匯入會先檢查所有檔案，再以同一筆 IndexedDB transaction 儲存，失敗時不會只留下部分歌曲。匯入會產生新的本機 ID，不依備份中的 ID 覆寫其他歌曲。相同譜面內容會略過；匯入 JSON 備份時也會還原已存在歌曲的閱讀設定。未儲存的編輯在關閉前會要求確認捨棄。

單首譜最多 256 KB，個人歌本最多 500 首、合計 10 MB。每次選取的匯入檔案合計最多 10 MB。

## 戰鬥閱讀

戰鬥時按「♬ 歌本」，只顯示選曲、歌詞與和弦，以及開始／暫停和捲動速度。新增、編輯、刪除、匯入、匯出與移調設定僅在營地提供。每首歌的字體、移調和捲動速度會保存在 IndexedDB，進入戰鬥時沿用。

自行播放音樂；捲動速度以 px/s 設定，不會與其他音樂 App 同步。關閉歌本、切到背景或手動觸控／滾輪操作會暫停自動捲動。

## 資料保存

資料庫名稱為 `sing-rpg-songbook`（版本 1），使用 `songs` 與 `settings` 兩個 object stores。只有最後選取的歌曲 ID 放在 `localStorage`。歌譜與閱讀設定都不會發送到網路。

保存範圍是目前裝置、瀏覽器與網站來源，不會跨裝置同步。清除網站資料、無痕工作階段結束或瀏覽器清理儲存空間可能移除資料，請使用匯出功能保留備份。無法使用 IndexedDB 時仍可閱讀與匯出內建示範，新增／匯入／編輯會停用，不會宣稱已保存。

## 專案內新增示範

在 `songs/` 放入可隨網站公開發布的 UTF-8 ChordPro 譜，再編輯 `index.json`：

```json
[
  { "id": "my-example", "file": "my-example.cho" }
]
```

`id` 使用不重複的英文字母、數字、底線或連字號。`file` 相對於 `songs/`，只能指向本站該目錄下的檔案。個人匯入的譜不需放進專案。

基本資訊可以記成：

```chordpro
{title: 歌名}
{artist: 作者}
{key: C}
{capo: 0}
{tempo: 90}
{time: 4/4}
```

讀譜器支援行內 `[C]` 和弦、段落、註解、文字 TAB、BPM 與拍號；`{meta: tempo 90}` 也可使用。再次指定速度會在該處標示速度變更。所有譜面以純文字呈現，不執行 HTML；未支援的獨立指令會略過。
