# Sing RPG · 霧林遠征

[開啟 GitHub Pages](https://gipapa.github.io/sing-rpg/)

停好車後，在 Apple Music 播放器按播放，再按「開始冒險」允許收音。可以展開「更換歌單」，貼上 Apple Music 可分享的播放列表網址。完整播放取決於 Apple 播放器辨識的訂閱登入狀態與地區曲庫，未登入時可試聽。頁面不需要開發者金鑰。

旅人自動前進。前兩次遭遇是守衛，第三次是鹿角騎士，之後循環。跟唱累積攻擊，安靜時保留進度。前五件掉落會依序解鎖新的角色外觀。回營後保留本次戰績和裝備，關閉分頁再回來可以繼續中斷的旅程。

遊戲只顯示動畫。麥克風訊號留在裝置，不錄音、不回放。本版用音量與週期性估計跟唱，原唱外放、說話和環境聲都可能誤判。藍牙收音路由與鎖屏、背景執行由手機系統決定。遊戲的進度獨立於播放器和歌曲時間。

## 本機開發

在 repo 目錄執行 `python3 -m http.server 8000`，開啟 `http://localhost:8000/`。手機使用 HTTPS Pages 網址。專案是原生 HTML、CSS、JavaScript 與 Canvas。GitHub Pages 從 main 分支根目錄部署。
