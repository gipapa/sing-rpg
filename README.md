## 每首歌，都有冒險相伴

- **你的歌單，就是旅途配樂。** 貼上 Apple Music 歌單，跟著喜歡的音樂唱，也可以選擇自動攻擊，輕鬆聽歌、看隊伍前進。
- **隨手打鼓，也能召喚招式。** 戰場非按鈕區域都能敲出鼓聲。每敲一下隨機累積 1–5%，集滿 100% 就會施放畫面招式。
- **八個國家，一段逐步揭開的故事。** 從苔冠王國出發，挑戰各國國主、招募旅途中的夥伴。每次重遊都會重新抽選路線、屬相與敵人。
- **收集戰利品，打造自己的遠征隊。** 1,152 種怪物、1,152 件裝備等你收藏。替自己與九名夥伴搭配衣裝、頭飾和武器，選出援護夥伴，用屬性刻印強化援護。
- **隨時出發，下次接著冒險。** 像素風戰場支援手機直向與橫向顯示，裝備與遠征進度自動保存在目前瀏覽器，回營休息後還能繼續旅程。

## 三步開始遊玩

1. **直接出發**：按「開始戰鬥」即可進入遠征，設定頁底部也有「繼續戰鬥」按鈕。戰鬥方式由營地的麥克風選擇決定：無麥克風自動攻擊，有麥克風則依聲音觸發攻擊，不再顯示模式選單。
2. 在戰鬥工具（☰）選「♫ 音樂」開啟 Apple Music 播放器。按播放開始聽歌，或展開「更換歌單」貼上自己的歌單分享連結。收起面板可繼續聽，回營時結束播放。
3. **享受冒險**：跟著音樂出發，每戰結束都會自動前往下一關。打完國主後自動從本國第一關重新遠征，首通劇情也會自動播放完畢、接續戰鬥。想休息時按「回營結算」，整理裝備、查看收藏。

一次出發就能持續遠征，途中不需要點擊戰利品或劇情確認。劇情前兩幕各停留 4 秒、最後一幕停留 5 秒，畫面會顯示倒數；首次遊玩預設無麥克風、自動戰鬥。使用麥克風途中若收音中斷，或暫停超過 10 秒，會自動改為自動攻擊。

Apple Music 完整播放取決於訂閱登入狀態與地區曲庫，未登入時可試聽；若內嵌播放器要求重新登入，可點「在 Apple Music 播放」後回到遊戲。

選擇麥克風後只在裝置內分析收音音量，聲音只在裝置內處理；環境聲與外放音樂可能影響判斷。使用藍牙免持麥克風時，音樂可能切換為通話音質，想維持音樂品質可選「無麥克風」。遊戲進度獨立於歌曲時間，螢幕常亮與背景執行受系統限制。音樂播放與麥克風系統授權需自行完成；若在車內使用，請停妥車輛後完成設定，行車途中無需觀看或操作畫面。保持網頁在前景，鎖屏、離開頁面或系統中斷仍可能暫停遊戲。

## 隨手打鼓與招式

遠征時輕點戰場的非按鈕區域，就會響起鼓聲並出現漣漪。每次敲擊都隨機集氣 1–5%，累積到 100% 自動施放招式。集氣可跨戰鬥保留，回營後重新開始。營地設定提供星弦落雨、月輪和鳴、花火旋舞、配色與「精簡動畫」選擇。

滿能量招式會開啟獨立演出視窗，暫停普攻、集氣與遠征進度，音樂與麥克風持續運作。星弦落雨以九個運鏡分鏡呈現：遠景推近、指尖撥弦低角度特寫、甩鏡到敵方、環繞蓄力魔法陣、搖臂仰望天上的星座豎琴、跟拍流星俯衝、命中定格與震屏、拉遠餘韻，最後以招式字卡收尾；月輪和鳴從月亮搖鏡而下，經月光入刃特寫、三輪環繞、月輪側飛追跡、渾天儀般縛身到月華崩解與碎光如雪；花火旋舞從一瓣落掌的極近特寫，到旋轉鏡頭的花風、升空花火綻放、花嵐俯衝與千花盛放。三招各自約 11.6 秒後才結算 6 點傷害（偏好減少動態時改為固定鏡頭、無閃光與震動），擊殺後取得戰利品；可按「略過演出」或 Escape 直接完成結算。切到背景時演出暫停，回營或離開頁面會取消未結算的招式。

戰場右上角「回營結算」旁的 ☰ 可展開或收起歌本、螢幕常亮與音樂控制。地圖各國名稱後方顯示該國敵人登錄率與裝備收藏率的平均值，重複取得不增加進度。

在營地設定開啟「精簡動畫」後，不會彈出招式演出視窗，也不播放戰場招式特效、敲鼓漣漪或 cut-in 進出動畫。招式立即結算傷害，只直接顯示角色大頭照、招式名稱與實際傷害的 cut-in，停留 0.8 秒後消失，戰鬥持續進行。關閉時才播放三招各自約 11.6 秒的完整戰鬥運鏡與特效。選項會保存於目前瀏覽器的遊戲存檔。

選擇麥克風後，每累積一秒超過門檻的有效聲音也會隨機增加 1–5% 招式能量，與敲鼓共用同一條能量。招式名稱下方以能量條呈現進度。施放時會彈出角色大頭照、招式名稱與實際傷害，普攻也持續進行。探索與戰利品階段放招會播放演出。

營地設定可上傳招式大頭照，圖片會置中裁成正方形並縮小，保存在目前瀏覽器。也能選擇「使用角色外觀」，讓 cut-in 使用目前角色配裝。

營地設定的「鼓聲音量」可調整為 0–100%，預設 85%，0% 為靜音。音量設定會保存在目前瀏覽器，下次開啟沿用。

開發者可在 `drum-spells.js` 的 `drumSpells` 加入招式，指定名稱、持續時間、配色、粒子數與繪製函式。繪製函式接收 0 到 1 的動畫進度。`drumColors` 可擴充配色，玩家選擇會保存到原有存檔，舊存檔採預設招式。

## 麥克風回聲與圖鑑剪影

營地設定的「麥克風與音訊」提供以下選項，保存於目前瀏覽器，下次出發時套用：

- **收音麥克風**：無麥克風（預設，自動戰鬥）、系統預設麥克風、手機／裝置內建，或按「讀取麥克風清單」後選擇瀏覽器提供的車機、耳機或其他裝置。讀取清單可能要求收音權限，暫時收音會在讀取後停止。明確指定的麥克風找不到或與瀏覽器回報不符時，會停止出發並提示原因，不改用其他裝置；重新連線或權限變更後可再讀取清單。
- **觸發音量**：0.1–20%，預設 2%，以濾波後音量的 RMS 門檻判斷。需連續約 0.15 秒超過門檻才算有效，忽略更短的瞬間聲音；不辨識人聲、音準或歌詞，背景音樂也可能觸發。
- **攻擊冷卻**：300–3000 ms，預設 1000 ms。有效聲音在冷卻結束後觸發一次普攻，持續有聲可依此間隔重複攻擊；安靜時不攻擊，但冷卻仍會倒數，不會補發先前冷卻中的聲音。探索、戰利品與招式集氣照常進行。
- **音訊模式**：雙向收音與播放（原本預設 `play-and-record`）、自動（`auto`）。回營或收音結束時恢復原本音訊設定。不提供與麥克風收音不相容的 `playback` 音訊模式。
- **音訊處理延遲偏好**：即時（`interactive`，原本預設）、平衡（`balanced`）、播放優先（`playback`）。這是 AudioContext 的延遲偏好，與上面的音訊模式是不同設定；瀏覽器不保證滿足偏好，亦無法消除藍牙傳輸與車機緩衝延遲。
- **回音消除、降噪、自動增益**：各自開關。原本預設為回音消除開啟，降噪與自動增益關閉；回音消除與降噪可能改變歌聲音色。瀏覽器可能忽略不支援的設定。

「回聲」設定提供播放麥克風回聲開關與 0–1000 ms 額外延遲，預設關閉、200 ms。設為 0 只取消程式額外加入的延遲。回營或收音中斷時停止回聲。建議戴耳機或先降低音響音量，避免外放聲音被反覆收回。

原本獨立的「藍牙音響測試」已移除，可自行選擇內建麥克風、自動音訊模式、即時延遲偏好，關閉三項收音處理，並開啟回聲、額外延遲設為 0 ms，重現原測試設定。

戰場顯示瀏覽器回報的收音裝置。手機外放、聽筒、耳機與藍牙的實際輸出由作業系統及瀏覽器決定；使用 iPhone 連藍牙車機時，請在控制中心確認輸出裝置。網頁無法保證或確認 A2DP 輸出，實際音質、路由與延遲仍需在手機及車機實測。選擇無麥克風時不要求收音權限、不建立收音 AudioContext，也不套用上述音訊處理設定。收音啟動失敗時留在營地顯示原因，可改選無麥克風後再出發。

怪物與裝備圖鑑的未登錄圖片會顯示全黑剪影，登錄後呈現完整配色。

## 歌本與彈唱

營地的「歌本」可新增、編輯、匯入、刪除與匯出 ChordPro 譜，也能移調與調整字體。個人歌譜和每首歌的閱讀設定存於目前瀏覽器的 IndexedDB，不上傳到網站。可匯出單首 `.cho` 或整本 JSON 備份，在另一台裝置匯入。

戰場的「♬ 歌本」只提供選曲、顯示與捲動，沿用營地設定。自行播放音樂，在譜面下方按三角形播放，會依 BPM、拍號與小節拍數捲譜，暫停後可接續；不會追蹤外部音樂 App。沒有小節或拍數標記的舊譜會標示拍數估算。已附兩首明文原創示範，開啟即可閱讀，不需金鑰。支援曲中速度、拍號變更與逐行指定拍數。使用與備份方法見 [songs/README.md](./songs/README.md)。

播放中點擊歌詞可跳到該句並繼續播放，上下滑動也會移動進度並維持播放。專案附有 [sing-rpg-chordpro skill](./.agents/skills/sing-rpg-chordpro/SKILL.md)，可用 `$sing-rpg-chordpro` 撰寫與驗證適用本讀譜器的歌譜。

## 技術簡介

專案是純前端的靜態網頁，使用原生 HTML、CSS 與 JavaScript ES Modules，不依賴前端框架，也不需要建置流程或後端服務。GitHub Pages 從 main 分支根目錄部署。

- **畫面與動畫**：營地介面使用 HTML／CSS，戰場、角色與裝備外觀使用 Canvas 2D 繪製，透過 `requestAnimationFrame` 更新動畫，並支援減少動態效果的系統偏好。
- **聲音偵測**：透過 `getUserMedia` 取得麥克風訊號，再用 Web Audio API 帶通濾波與 512 點時域音量取樣，每 100 ms 進行一次線性的 RMS 計算。移除原本的週期性／自相關迴圈，以音量門檻與短暫持續時間判定有效聲音；攻擊冷卻由戰鬥時鐘處理，與聲音門檻及招式集氣分開。訊號只在裝置內處理。
- **遊戲邏輯與存檔**：遠征以探索、戰鬥、戰利品三種狀態推進，與畫面繪製分開處理。角色配裝、圖鑑、各國進度與歌單設定以 JSON 存入 `localStorage`，保存在目前瀏覽器。
- **音樂與螢幕常亮**：Apple Music 透過 iframe 內嵌播放器播放，遊戲不讀取歌曲音訊或播放時間。戰鬥期間使用 Screen Wake Lock API 要求螢幕常亮，實際支援與允許情況由瀏覽器及系統決定。

主要檔案分工：

## 本機開發

在 repo 目錄啟動靜態伺服器：

```sh
python3 -m http.server 8000
```

開啟 `http://localhost:8000/` 即可遊玩，不需要安裝 npm 套件。麥克風需要安全來源；本機可使用 localhost，手機請使用 HTTPS Pages 網址。

使用支援 ES Modules 自動辨識的新版 Node.js 執行遊戲邏輯測試：

```sh
node --test test/*.test.mjs
```

測試涵蓋圖鑑資料完整性、各國進度保存、八國通關、夥伴招募、倒數與取消操作、首通後接續遠征、模擬 90 分鐘的循環戰鬥，以及打鼓隨機集氣、回聲音訊連線與設定預設值。

若已安裝 `agent-browser`，執行 `python3 test/browser_regressions.py` 可在獨立瀏覽器工作階段驗證分頁接手、存檔重試、麥克風授權取消、手機捲譜和招式載入。測試會自行啟停本機伺服器。
