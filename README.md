# Sing RPG · 霧林遠征

[開啟 GitHub Pages](https://gipapa.github.io/sing-rpg/)

停好車後，在 Apple Music 播放器按播放，再按「開始戰鬥」。每次開始或繼續戰鬥時都會跳出兩個選項，點選模式後立即出發。可以展開「更換歌單」，貼上 Apple Music 可分享的播放列表網址。完整播放取決於 Apple 播放器辨識的訂閱登入狀態與地區曲庫，未登入時可試聽。頁面不需要開發者金鑰。

開始後戰場在原分頁鋪滿視窗，直向與橫向皆可使用。點「♫ 音樂」可展開原本的 Apple Music 播放器，暫停或在歌單選曲，收起後接著看戰鬥。前景戰鬥會要求螢幕常亮，回營會解除，是否允許取決於系統。按「回營結算」收隊；裝備與進度存在這個瀏覽器。

「跟唱模式」是預設選項，選取後才會開啟系統預設麥克風。使用車機的免持麥克風時，音樂可能轉為通話音質。「高音質模式」全程不要求麥克風權限，角色會自動攻擊。

遊戲只顯示動畫。麥克風訊號留在裝置，不錄音、不回放。本版用音量與週期性估計跟唱，原唱外放、說話和環境聲都可能誤判。藍牙收音路由與鎖屏、背景執行由手機系統決定。遊戲的進度獨立於播放器和歌曲時間。

## 本機開發

在 repo 目錄執行 `python3 -m http.server 8000`，開啟 `http://localhost:8000/`。手機使用 HTTPS Pages 網址。專案是原生 HTML、CSS、JavaScript 與 Canvas。GitHub Pages 從 main 分支根目錄部署。
