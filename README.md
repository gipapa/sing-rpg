# 轉生異世界無法成為勇者只好轉職吟遊詩人拯救世界 · sing rpg

[開啟 GitHub Pages](https://gipapa.github.io/sing-rpg/)

停好車後，在 Apple Music 播放器按播放，再按「開始戰鬥」。每次開始或繼續戰鬥時都會跳出兩個選項，點選模式後立即出發。可以展開「更換歌單」，貼上 Apple Music 可分享的播放列表網址。完整播放取決於 Apple 播放器辨識的訂閱登入狀態與地區曲庫，未登入時可試聽。同一份歌單會沿用原有播放器。內嵌播放器若要求重新登入，可選「在 Apple Music 播放」，播放後回到遊戲。

開始後戰場在原分頁鋪滿視窗，直向與橫向皆可使用。點「♫ 音樂」可展開原本的 Apple Music 播放器，暫停或在歌單選曲，收起後接著看戰鬥。前景戰鬥會要求螢幕常亮，回營會解除，是否允許取決於系統。按「回營結算」收隊；裝備與進度存在這個瀏覽器。

## 八國遠征

吟遊詩人預設名為「あああ」，可在營地的「設定」修改。旅歌手洛陪你前往苔冠王國尋找公主。每趟穿越四處地標，每區三戰，最後一戰迎戰國主。首次通關會播放三幕故事並招募一名夥伴。打通苔冠後可任選中間六國，集齊七國線索後開放暮星王庭。救出蕾雅後，公主也能同行。重遊時會重新抽選路線、屬相與敵人，打完國主後自動展開下一趟。

八國各有四處地標、三種副屬，共 96 個區域組合。怪物圖鑑收錄 1,152 種，進入戰鬥即登錄。裝備圖鑑收錄 1,152 件，每次勝利取得一件，國主優先掉落當地當前屬相尚未收藏的裝備。兩本圖鑑均可依國家、名稱與登錄狀態查詢。

在「夥伴整備」替吟遊詩人或九名可招募的夥伴更換衣裝、頭飾與武器。所有已招募的夥伴一同出發，可指定一位負責援護。裝備收藏全隊共用，每人的配裝獨立保存。與當區副屬相符的刻印會增強同行夥伴的援護。回營換國或關閉網頁會保存各國所在區域、當前敵人與戰鬥進度。

「跟唱模式」是預設選項，選取後才會開啟系統預設麥克風。使用車機的免持麥克風時，音樂可能轉為通話音質。「高音質模式」全程不要求麥克風權限，角色會自動攻擊。

遊戲只顯示動畫。麥克風訊號留在裝置，不錄音、不回放。本版用音量與週期性估計跟唱，原唱外放、說話和環境聲都可能誤判。藍牙收音路由與鎖屏、背景執行由手機系統決定。遊戲的進度獨立於播放器和歌曲時間。

## 本機開發

在 repo 目錄執行 `python3 -m http.server 8000`，開啟 `http://localhost:8000/`。手機使用 HTTPS Pages 網址。專案是原生 HTML、CSS、JavaScript 與 Canvas。GitHub Pages 從 main 分支根目錄部署。
