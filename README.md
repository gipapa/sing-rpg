**播放喜歡的歌，用歌聲帶領隊伍，踏上拯救世界的旅程。**

轉生異世界的你，選擇以吟遊詩人的身分出發。讓熟悉的旋律陪你穿越森林、群島與雪國，跟著唱，為隊伍累積攻擊；在一次次勝利中收集裝備、結識夥伴，追尋失蹤公主的線索。

打開網頁就能開始。讓每天聽歌的時間，多一場值得期待的冒險。

## 每首歌，都有冒險相伴

- **你的歌單，就是旅途配樂。** 貼上 Apple Music 歌單，跟著喜歡的音樂唱，也可以選擇自動攻擊，輕鬆聽歌、看隊伍前進。
- **八個國家，一段逐步揭開的故事。** 從苔冠王國出發，挑戰各國國主、招募旅途中的夥伴。每次重遊都會重新抽選路線、屬相與敵人。
- **收集戰利品，打造自己的遠征隊。** 1,152 種怪物、1,152 件裝備等你收藏。替自己與九名夥伴搭配衣裝、頭飾和武器，選出援護夥伴，用屬性刻印強化援護。
- **隨時出發，下次接著冒險。** 像素風戰場支援手機直向與橫向顯示，裝備與遠征進度自動保存在目前瀏覽器，回營休息後還能繼續旅程。

## 三步開始遊玩

1. **播放音樂**：在頁面上的 Apple Music 播放器按播放，或展開「更換歌單」貼上自己的歌單分享連結。
2. **選擇模式**：按「開始戰鬥」，選擇開啟麥克風的「跟唱模式」，或不需麥克風、自動攻擊的「高音質模式」。
3. **享受冒險**：跟著音樂出發，每戰結束都會自動前往下一關。打完國主後自動從本國第一關重新遠征，首通劇情也會自動播放完畢、接續戰鬥。想休息時按「回營結算」，整理裝備、查看收藏。

一次出發就能持續遠征，途中不需要點擊戰利品或劇情確認。劇情前兩幕各停留 4 秒、最後一幕停留 5 秒，畫面會顯示倒數；模式選單等待 10 秒後會以高音質模式自動出發。跟唱途中若收音中斷，或暫停超過 10 秒，會自動改為自動攻擊。

Apple Music 完整播放取決於訂閱登入狀態與地區曲庫，未登入時可試聽；若內嵌播放器要求重新登入，可點「在 Apple Music 播放」後回到遊戲。

跟唱模式只在裝置內分析麥克風訊號，不錄音、不回放；環境聲與外放音樂可能影響判斷。使用藍牙免持麥克風時，音樂可能切換為通話音質，想維持音樂品質可選「高音質模式」。遊戲進度獨立於歌曲時間，螢幕常亮與背景執行受系統限制。音樂播放與麥克風系統授權需自行完成；若在車內使用，請停妥車輛後完成設定，行車途中無需觀看或操作畫面。保持網頁在前景，鎖屏、離開頁面或系統中斷仍可能暫停遊戲。

## 技術簡介

專案是純前端的靜態網頁，使用原生 HTML、CSS 與 JavaScript ES Modules，不依賴前端框架，也不需要建置流程或後端服務。GitHub Pages 從 main 分支根目錄部署。

- **畫面與動畫**：營地介面使用 HTML／CSS，戰場、角色與裝備外觀使用 Canvas 2D 繪製，透過 `requestAnimationFrame` 更新動畫，並支援減少動態效果的系統偏好。
- **跟唱偵測**：透過 `getUserMedia` 取得麥克風訊號，再用 Web Audio API 進行帶通濾波、音量與週期性分析，判斷是否持續發聲來累積攻擊。這是聲音特徵估計，不會辨識歌詞或比對歌曲音準；訊號只在裝置內處理。
- **遊戲邏輯與存檔**：遠征以探索、戰鬥、戰利品三種狀態推進，與畫面繪製分開處理。角色配裝、圖鑑、各國進度與歌單設定以 JSON 存入 `localStorage`，保存在目前瀏覽器。
- **音樂與螢幕常亮**：Apple Music 透過 iframe 內嵌播放器播放，遊戲不讀取歌曲音訊或播放時間。戰鬥期間使用 Screen Wake Lock API 要求螢幕常亮，實際支援與允許情況由瀏覽器及系統決定。

主要檔案分工：

| 檔案 | 用途 |
| --- | --- |
| `index.html`、`style.css` | 頁面結構、營地與戰場版面、響應式樣式 |
| `app.js` | 串接遊戲流程、模式切換、播放器與存檔 |
| `adventure.js` | 路線抽選、戰鬥、掉落與通關邏輯 |
| `catalog.js` | 國家、夥伴、怪物、裝備資料與初始遊戲狀態 |
| `camp.js` | 地圖、夥伴整備、圖鑑、設定與故事介面 |
| `scene.js` | Canvas 場景、角色與戰鬥動畫繪製 |
| `mic.js`、`screen.js` | 麥克風分析與螢幕常亮管理 |
| `countdown.js` | 劇情與模式選單的自動前進倒數 |

## 本機開發

在 repo 目錄啟動靜態伺服器：

```sh
python3 -m http.server 8000
```

開啟 `http://localhost:8000/` 即可遊玩，不需要安裝 npm 套件。麥克風需要安全來源；本機可使用 localhost，手機請使用 HTTPS Pages 網址。

使用支援 ES Modules 自動辨識的新版 Node.js 執行遊戲邏輯測試：

```sh
node --test test/*.test.mjs
```

測試涵蓋圖鑑資料完整性、各國進度保存、八國通關、夥伴招募、倒數與取消操作、首通後接續遠征與模擬 90 分鐘的循環戰鬥。
